# sciencemadereadable.com

Real research papers, rewritten in plain words: every finding kept, nothing dumbed down.

This repository holds the published site (built files). The small open models that do the
rewriting run on a home GPU; readers can also use their own Anthropic or OpenAI key to compare
with commercial models. Papers come from PubMed Central (open access, CC BY), and the original
figures and tables are always shown.
