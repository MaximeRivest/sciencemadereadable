Teaching a small model to write science

A 0.8-billion-parameter model is learning to write a scientific paper for a curious 14-year-old, from a bundle of facts, definitions and a plan, without ever seeing the paper. If it writes well, good writing does not need the science to be stored in the model.

The model reads each training section once (one pass). In each step it reads 16 sections, compares what it would have written with what the teacher (Opus or Astra) wrote, and adjusts itself a little.

How well it is learning

on papers it learns from   on 20 held-back papers it never learns from   the first run's best on the same held-back papers: the line to beat

Lower is better. The number (the "loss") measures how surprised the model is by the teacher's next word. The green line is the honest one: papers it never trains on. If orange keeps falling but green rises, the model is memorising instead of learning; that is what happened in the first run after one pass.

Facts kept right: an Opus checker compares every fact in the bundle with the model's text. The teachers keep about 98%; the first 0.8B kept 56%. Numbers in its text is a free, automatic check: the share of the bundle's numbers that appear. Form errors: missing figure placeholders, missing citations, lists.
